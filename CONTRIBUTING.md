
# Contributing

Thank you for your interest in contributing!

We welcome contributions from:
- Software developers
- Arabic language educators
- Researchers
- Students and learners

Before contributing:
1. Read the project README.
2. Discuss significant changes before implementation.
3. Submit clear and focused contributions.
4. Include tests when appropriate.
5. Respect educational content accuracy and licensing.

All contributions should support the project's educational mission.
